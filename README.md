# Agropacking Aconcagua - Landing Page

Landing page corporativa desarrollada para **Agropacking Aconcagua**, especializada en servicios técnicos, fabricación, certificación y mantención de cámaras de SO₂ para la postcosecha en el Valle del Aconcagua.

## Tecnologías Utilizadas
* **React** (Vite)
* **Tailwind CSS** (Estilos y diseño responsivo)
* **React Icons** (Iconografía)
* **Netlify Forms** (Gestión de leads y formularios de contacto)

## Estructura del Proyecto
* `src/components/`: Componentes modulares (`Navbar`, `Hero`, `Empresa`, `Servicios`, `Galeria`, `Contacto`, `Footer`).
* `src/assets/`: Recursos gráficos y multimedia optimizados.
